# 1. PROJECT INTRODUCTION

ML-012 is a Machine Learning project based on agriculture.

The purpose of this project is to classify crop categories using basic soil nutrients and weather conditions.

Different crops have different soil and environmental requirements. Our dataset contains information about soil nutrients, temperature, humidity, soil pH, and rainfall.

We use this information to train a Machine Learning model.

After training, the model can accept new input values and predict a crop category.

In simple words:

We provide soil and weather information to our trained model, and the model predicts which crop category matches those conditions based on patterns learned from the dataset.

# 7. MACHINE LEARNING CONCEPTS USED

## 7.1 Supervised Learning

Our project uses Supervised Learning.

Supervised Learning means training a model using data that already contains correct answers.

In our dataset:

* Input: Soil and weather measurements.
* Output: Actual crop label.

The model learns the relationship between inputs and labels.

## 7.2 Classification

Classification is a Machine Learning task in which a model predicts a category.

Our project uses Multi-Class Classification because there are 22 possible crop categories.

## 7.3 Features and Target

Features are the input variables used by the model.

Our seven features are:

N, P, K, Temperature, Humidity, pH, Rainfall.

The target is:

Label.

The target contains the actual crop category.

# 8. MACHINE LEARNING ALGORITHMS

We train and compare four algorithms.

## 8.1 Decision Tree Classifier

Decision Tree works like a flowchart.

It divides the dataset into smaller groups using conditions based on input features.

It makes a final prediction at a leaf node.

Advantages:

* Easy to understand.
* Easy to visualize.
* Works with classification problems.

## 8.2 Random Forest Classifier

Random Forest combines multiple Decision Trees.

Each tree makes a prediction, and the forest combines their predictions to produce the final result.

Advantages:

* Combines multiple decision trees.
* Can capture complex patterns.
* Often performs well on structured datasets.

## 8.3 K-Nearest Neighbors (KNN)

KNN predicts a category by finding the nearest training examples to the new input.

It uses the categories of nearby data points to determine the prediction.

Advantages:

* Easy to understand.
* Simple classification method.
* Useful for comparison.

Note: Feature scaling can be important for KNN because it uses distances.

## 8.4 Logistic Regression

Logistic Regression estimates probabilities for different classes.

It selects the class with the highest predicted probability.

Advantages:

* Simple classification algorithm.
* Provides a useful baseline.
* Helps compare different approaches.

We compare all four models using their test performance.

The model with the best test accuracy is selected for further evaluation.

# 11. MODEL EVALUATION METRICS

## Accuracy

Accuracy measures the percentage of correct predictions.

## Precision

Precision measures how many predictions for a particular class were correct.

## Recall

Recall measures how many actual examples of a class were correctly identified.

## F1-Score

F1-score combines Precision and Recall.

## Confusion Matrix

A confusion matrix shows correct and incorrect predictions for each crop category.

## Cross-Validation

Cross-validation evaluates model performance across multiple training and validation splits.

We use five-fold cross-validation.
