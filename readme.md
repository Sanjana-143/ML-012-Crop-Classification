# ML-012: Crop Type Classification from Basic Soil Data

## Project Overview

ML-012 is a Machine Learning project that classifies crop categories using soil nutrients and environmental conditions.

The project explores how supervised machine learning algorithms can identify patterns in agricultural datasets.

## Objectives

* Analyze soil and weather data.
* Perform exploratory data analysis.
* Train multiple classification algorithms.
* Compare model performance.
* Identify important features.
* Predict crop categories using input parameters.

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Joblib

## Dataset Features

| Feature     | Description   |
| ----------- | ------------- |
| N           | Nitrogen      |
| P           | Phosphorus    |
| K           | Potassium     |
| Temperature | Temperature   |
| Humidity    | Humidity      |
| pH          | Soil pH       |
| Rainfall    | Rainfall      |
| Label       | Crop category |
